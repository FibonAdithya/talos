# AI working notes

Everything in this directory was written by a coding agent during
development: design specs in `specs/`, implementation plans in `plans/`.

**These are not the source of truth.** They record what was intended at the
time of writing and are not updated as the code changes. Where any file here
disagrees with the code or with the human-maintained documents that
`AGENTS.md` lists as authoritative, those win.

They are kept because the reasoning behind a decision is often more useful
than the decision, and that reasoning is not recoverable from a diff.

Agents writing a new spec or plan put it here: design specs in `specs/`,
implementation plans in `plans/`, named `YYYY-MM-DD-<topic>.md`. Never in
another directory.
